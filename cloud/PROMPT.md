# Symphony

## Overview
A hardware-enabled way for small-med sized business to run AI on prem and save money through efficient prompt routing. Lots of companies today want to move towards running AI on prem and not training frontier models over public APIs. Businesses want to protect their data, their intellectual property, and start running ai on prem. The goal of our project is to implement a hardware-based all in one solution for us to come in, setup for a business, and gain revenue through a hardware piece that we sell (jetson orin nano) and setting up their cloud environment. 

## Scope
- small to medium sized business looking to use AI locally to keep their business trade secrets away from frontier models that train on publicly used data. That way, business can sure their data is protected through the hardware we setup, and maintain for them.

## Local AI models
- Jetson orin nano that runs a decision model and a local small model. The decision model decides where to route the prompt to, depending on its threshold factor. we use the same weights for the deicison model then swap the header to run the same weights with LMhead to use the model on the nano to run a bigger param model but with a head swap. keeps latency low as well. 

## The routing layer. 
- based on what the decision model tells us the best place to send the prompt is, we route the prompt to that specific model. We want three main environments for the prompt to end up, and depnding on tools calls as well. We should have a local model that runs on the nano for simple prompts with no tools. Then, there is a bedrock model running a lower tier model with tools defined in agent core where the agents also run but its where the private data is kept. We want to encrypt traffic between the cloud and our on prem devices via some cheap method, tailscale or some aws cloud service. 

- for any prmopt that is quite complex and would require tool calls that require connectors etc, we can use snowflake api to route it to the frontier models for relatively cheap.
